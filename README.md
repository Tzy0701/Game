# 🦎 变色龙躲猫猫 · Chameleon Party

一款致敬 **《Meccha Chameleon》** 的浏览器 3D 联机躲猫猫游戏。
变色龙要**亲手给自己全身涂装**、摆好姿势融入环境；猎人要在时间内把他们一个个揪出来！

打开网页就能玩，**不需要安装、不需要自建服务器**。朋友之间通过房间码 / 邀请链接直接 P2P 联机（最多 24 人）。

## 玩法

| 身份 | 目标 |
| --- | --- |
| 🦎 **变色龙** | 躲藏阶段内找好位置，按 <kbd>F</kbd> 进入涂装模式，用画笔 / 吸管 / 填充把自己涂成和墙壁、地板、家具一样的颜色和花纹，再摆一个合适的姿势。坚持到时间结束就赢！ |
| 🔫 **猎人** | 躲藏阶段会被蒙眼。寻找阶段用鼠标左键射击可疑的东西——打中变色龙就抓到了（+100 分），打空会有 1.3 秒冷却。抓光所有变色龙即获胜。 |

- 被抓到的变色龙会变成观战幽灵，可以自由飞行围观。
- 变色龙按 <kbd>T</kbd> 可以**嘲讽**：+10 分，但会发出声音暴露位置。
- 大厅里所有人都可以自由涂装、练习；按 <kbd>H</kbd> 切换到猎人视角，试试能不能找到朋友。
- 房主每回合会自动轮换猎人，可以设置地图、躲藏/寻找时间、猎人数量。

### 操作

| 按键 | 作用 | 按键 | 作用 |
| --- | --- | --- | --- |
| WASD | 移动 | 空格 | 跳跃 |
| Shift | 奔跑 | 鼠标 | 视角 |
| F | 进入 / 退出涂装模式 | 1-9 | 姿势（站立、蹲下、坐下、T 字、举手、大字、趴下、平躺、倒立） |
| E | 吸取准星处的颜色 | T | 嘲讽 |
| V | 第一 / 第三人称 | Tab | 计分板 |
| Enter | 聊天 | Esc | 房间面板 |

**涂装模式**：左键使用工具（画笔 B / 喷点 N / 填满一面 G / 填满部件 K / 吸管 I），<kbd>Shift</kbd>+左键快速吸色，右键拖动旋转镜头，滚轮缩放，<kbd>Q</kbd>/<kbd>E</kbd> 转身，<kbd>[</kbd> <kbd>]</kbd> 调笔刷大小。

> 小技巧：吸管取到的是表面的**原始颜色**（不含光照），所以站在和墙面同样光照的地方效果最好。条纹墙可以先“填满一面”再用画笔补条纹！

## 怎么和朋友一起玩

### 方式一：部署到 GitHub Pages（推荐，一次设置永久可用）

1. 把代码合并到 `main` 分支。
2. 在 GitHub 仓库 **Settings → Pages → Build and deployment → Source** 选择 **GitHub Actions**。
3. 推送到 `main` 后会自动部署，地址类似 `https://<你的用户名>.github.io/<仓库名>/`。
4. 打开网址 → **创建房间** → 点 **复制邀请链接** 发给朋友，朋友打开链接点 **加入房间** 即可。

### 方式二：本地运行

需要用任意静态服务器打开（直接双击 `index.html` 不行，因为浏览器禁止 file:// 加载模块）：

```bash
# 任选其一
python3 -m http.server 8080
npx http-server -p 8080
```

然后浏览器打开 <http://localhost:8080>。本地运行时一样可以和外网的朋友联机（大家打开同一个网址，或者各自本地打开也行，只要房间码一致）。

## 技术说明

- 纯前端：[three.js](https://threejs.org/) 渲染，[PeerJS](https://peerjs.com/)（WebRTC）联机，库文件已放在 `lib/` 目录，不依赖外部 CDN。
- 房主的浏览器同时充当游戏服务器（负责回合、计时、判定），其他人通过 WebRTC 直连房主。**房主请保持页面在前台打开**，房主离开房间会解散。
- 联机信令使用 PeerJS 的免费公共服务器（`0.peerjs.com`）。如果它不稳定，可以自建 [PeerServer](https://github.com/peers/peerjs-server)，然后在网址后加参数：`?peerhost=你的服务器&peerport=443`。
- 少数严格的公司/校园网络可能无法建立 P2P 连接，换手机热点通常就好了。
- 开发调试：网址加 `?net=local` 可以在同一浏览器的多个标签页之间联机测试。

